Stump's contract is the product it is built to be: every promise, with how each one is checked. The [full contract](/contract) shows each clause and its status.

## How to read it

- Each clause has an id that keeps its meaning for life, such as `STUMP-VENUE-001`.
- A clause is done only when every one of its checks works through Stump's own doors.
- The first release's promises are its published clauses; the rest are targets.

## Door rules

A few rules hold for every door, for people and agents alike:

- **Real identity.** Everyone signed in by invitation, and every account belongs to one of them or to the company.
- **Disclosure.** A connection to the company is said before a post moves on. See [Disclosure](/docs/disclosure).
- **Venue rules decide the route.** See [Venues and rules](/docs/venues).
- **No banned acts.** See [What Stump refuses](/docs/refusals).
- **Delivery truth.** A post reads as posted only with the network's own id and link read back, or the link the named person recorded.
- **Untrusted text.** Text found, imported or received is data, and never changes a rule, a route or a role.
